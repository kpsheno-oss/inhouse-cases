# INHOUSE MEDIA — презентация для сайта

Автономная веб-версия презентации «INHOUSE MEDIA — девелоперы контента». Она не зависит от claude.ai: всё, что нужно, лежит в этой папке.

## Что внутри

```
index.html   — страница с плеером и всеми 41 слайдом
media/       — изображения (jpg/png/svg) и видео (mp4, H.264)
fonts/       — шрифты Druk Text Wide Cyr, TT Norms и иконки
```

Шрифт Golos Text подключается из Google Fonts.

## Как разместить

Адрес презентации: **https://inhouse.media/cases/**

1. Скопируйте содержимое папки `inhouse-presentation` (не саму папку, а то, что внутри) в каталог `cases` в корне сайта inhouse.media. Должно получиться `…/cases/index.html`, `…/cases/media/`, `…/cases/fonts/`.
2. Откройте https://inhouse.media/cases/ и проверьте.

Адрес без косой черты на конце (`inhouse.media/cases`) тоже работает: страница сама перенаправит на `/cases/`. Надёжнее настроить такой редирект и на сервере (см. пример nginx ниже).

Это обычные статические файлы. Серверный код, база данных и сборка не нужны. Подойдёт любой хостинг, куда можно загрузить папку с файлами: nginx, Apache, S3, Yandex Object Storage, Netlify, GitHub Pages. Если inhouse.media сделан на конструкторе (Tilda и т.п.) и загрузить туда папку нельзя, разместите файлы на файловом хостинге и настройте на конструкторе страницу `/cases` с редиректом или iframe на них (см. «Встроить в страницу сайта»).

Структуру папок не меняйте: пути внутри `index.html` относительные.

## Настройки сервера

- **Видео.** Сервер должен отдавать `.mp4` с типом `video/mp4` и поддерживать Range-запросы. Это так по умолчанию у nginx, Apache и облачных хранилищ. Без Range видео в Safari и на iPhone не запустится.
- **Шрифты.** Типы `font/otf`, `font/ttf`, `font/woff2`. Если шрифты кладутся на отдельный CDN-домен, нужен заголовок `Access-Control-Allow-Origin`.
- **Кэш.** Файлы в `media/` и `fonts/` не меняются, им можно выставить долгий кэш (например, `Cache-Control: max-age=31536000, immutable`). Для `index.html` кэш лучше короткий.
- **Сжатие.** Включите gzip/brotli для `index.html` (≈140 КБ → ≈25 КБ).

Пример для nginx:

```nginx
location = /cases {
    return 301 /cases/;
}
location /cases/ {
    alias /var/www/inhouse.media/cases/;
    index index.html;
    location ~* \.(mp4|jpg|png|svg|otf|ttf|woff2)$ {
        add_header Cache-Control "public, max-age=31536000, immutable";
    }
}
```

## Управление

- Стрелки ← →, пробел, PageUp/PageDown, колёсико мыши — листать.
- Клик по правой части экрана — вперёд, по левой трети — назад; на телефоне — свайп.
- `F` — полный экран, `G` — все слайды.
- Клик по видео ставит его на паузу или запускает.
- Ссылка на конкретный слайд: `https://inhouse.media/cases/#12`.

Анимации появления элементов, переходы между слайдами и видео работают так же, как в оригинале: видео играют без звука по кругу, пока открыт их слайд.

## Встроить в страницу сайта

Если презентация должна стоять внутри другой страницы, а не открываться отдельно:

```html
<iframe src="https://inhouse.media/cases/" style="width:100%;aspect-ratio:16/9;border:0" allow="fullscreen" allowfullscreen loading="lazy"></iframe>
```

## Объём

Около 140 МБ, почти всё — 30 видео. Страница грузит видео только для текущего и соседних слайдов, поэтому первая загрузка лёгкая.
